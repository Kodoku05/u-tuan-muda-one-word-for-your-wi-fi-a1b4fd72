One word for your Wi-Fi: **Liar**. Full bars, nothing loads — the signal lies to your face. The most universal home Wi-Fi truth in a single instantly understood word, and a funny network name: every guest gets the joke. Not "slow" or "weak" like every other entry — the dishonest signal is the surprise angle.

## Run it

```sh
node main.ts
```

Writes `Liar` (4 bytes, no trailing newline) to `/output/entry.txt`. Node 22 standard library only, no network, no secrets, deterministic.
